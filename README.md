# PostgreSQL DVD Rental Analysis

## Project Overview

This project explores SQL joins and data filtering using the PostgreSQL DVD Rental sample database.

The goal is to practice retrieving and combining information from related database tables.

## SQL Concepts Practiced

- INNER JOIN and LEFT JOIN
- SELF JOIN
- WHERE and BETWEEN
- LIKE
- ORDER BY and LIMIT
- Table aliases

## Queries

1. Retrieve customer names and rental dates using INNER JOIN.
2. Connect customers with their payment records using LEFT JOIN.
3. Filter customer payments between $5 and $10.
4. Find movie titles starting with the letter A and display their languages.
5. Identify pairs of films with matching rental durations using SELF JOIN.

## Tools

- PostgreSQL 18
- pgAdmin 4
- SQL

## Dataset

DVD Rental sample database from [PostgreSQL Tutorial](https://www.postgresqltutorial.com/postgresql-getting-started/postgresql-sample-database/).
